**Ember & Egg — Dapur Perapian**: a complete, original cooking game for make.fun's "Make the best cooking game" bounty. You are the cook of a small hearth kitchen: grab ingredients from the crates, chop them on the board, fry them in the pans, assemble dishes on the plating counter, and serve them at the window before the order timers run out. Four original recipes, a 3-minute shift, combo bonuses, and a burn risk if you leave a pan too long.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or just open `game/index.html` from any static server. The game is plain static files under `game/` (no build step, no network requests, all art drawn in code, all sounds synthesized with WebAudio).

Controls: WASD / arrows to walk, E / Space / click to use a station, P pause, R restart, M mute.
